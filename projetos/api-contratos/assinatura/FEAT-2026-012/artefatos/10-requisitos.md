# Requisitos da assinatura digital

## Situação
O contrato é emitido no sistema de originação fictício.
O cliente precisa assinar antes de concluir a emissão.

## Funcionais
RF-001: apresentar a assinatura na tela de emissão.
RF-002: guardar o identificador devolvido pelo serviço de assinatura.

## Não funcional
RNF-001: acrescentar no máximo 3 segundos à emissão.
A medição de desempenho ainda será feita.

## Limite
Este documento não define um provedor de assinatura real.
